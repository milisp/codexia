# 0.46.0 - 2026-08-16

[Compare with 0.45.0](https://github.com/milisp/codexia/compare/v0.45.0...v0.46.0)

## Added

- **Ghibli accent theme** — a new theme with a scene backdrop, with follow-up polish to keep the thread surface and message backdrop readable in both light and dark mode (`35c3051f`, `4f8fba87`, `1035ac98`).
- **Open-app support** — open files and projects in external apps, with icons and both Tauri and web command paths (`d5f19b2e`).
- **Agent QA recommendation** — the tools panel can now recommend Agent QA (`accf9fda`).

## Changed

- **Project relicensed under MIT** (`1209c1e8`).
- ChatGPT login moved into a dialog opened from the user menu, out of the main thread view (`c1db0a08`).

## Removed

- PostHog analytics (`11ae698a`).

## Fixed

- Codex thread list now filters by the selected provider and preserves the previously loaded page size (`e609e2bd`).

## Internal

BashTool was simplified with an expandable command view and a copy button.
