# 0.44.0 - 2026-08-10

[Compare with 0.43.0](https://github.com/milisp/codexia/compare/v0.43.0...v0.44.0)

## Added

- **Effort level for Claude Code** — pick low, medium, high, xhigh or max from the model selector, now a popover with a dedicated effort slider shared with the codex selector (`950afa1a`, `5b1ed833`).
- **New Claude Code permission modes** — `auto`, `dontAsk` and `manual`, with matching hook behavior, plus the `fable` model option (`950afa1a`).
- **Claude env variable editor** — edit the `env` field of `~/.claude/settings.json` from Settings > Claude, with a shortcut that inserts the gateway-related keys (`ANTHROPIC_BASE_URL`, `ANTHROPIC_AUTH_TOKEN`, the `ANTHROPIC_DEFAULT_*_MODEL` overrides and more) (`df4ce453`).
- **Automation runner** — run automations on a configurable worktree; orphaned runs are failed on startup, and quitting asks for confirmation while a workspace still has active work (`31f35391`, `069b2a0c`).
- **Custom background image and starfield effect** in theme settings (`9089f22b`).
- **Hidden providers** — providers can be hidden from the model selector (`6a8839eb`).
- **Windows portable archive** published as a release asset, and Scoop install documented in the README (`f4e1ab03`, `c4d5f3df`, `7483a437`).

## Changed

- Reasoning effort selection split into its own `ReasoningEffortSelector`, replacing the old model list (`6a8839eb`).
- Model lists are cached in a shared store, so they are fetched once instead of per selector instance (`6a8839eb`).
- Provider env status is read from the shell profile in one batch lookup instead of once per key (`6a8839eb`).

## Fixed

- Creating or resuming a Claude Code session without a working directory is now blocked instead of failing later (`950afa1a`).

## Internal

Upgraded claude-agent-sdk-rs to v0.8.0, dropped the `codex-protocol` dependency in favor of local types, moved `src/types/codex/*` into `src/components/codex/types/`, typed the cc session options payload, and extracted shared file-change utilities and the rate limit hook into their own modules.
