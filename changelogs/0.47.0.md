# 0.47.0 - 2026-08-18

[Compare with 0.46.0](https://github.com/milisp/codexia/compare/v0.46.0...v0.47.0)

## Added

- **New composer** — the message input is now a Lexical editor with `$` mention chips for files and context (`21b99ffb`), plus a slash command registry providing `/compact`, `/init`, `/memories` and friends (`5e512d10`).
- **User-managed model providers** — add and edit your own providers from settings (`14b73dc1`), with LM Studio available as a built-in provider (`d1f6aba1`).
- **OAuth login for remote MCP servers** (`31ab6e06`).
- **Plugin marketplace search and categories**, with requests routed to the correct targets (`7d5d6875`).
- **French translation** (`de7e1036`).
- **Thread and session pinning**, persisted across restarts (`079afe5f`).
- **Long-press context menu on touch devices**, with text selection disabled where it interfered (`62538076`).
- **Sidebar update indicator** replaces the old update button (`4da5cd6c`).
- Recommended tools are now fetched from the latest `recommend.json` on GitHub when the view mounts (`aaa63742`), and ClawMetry was added to the list (`98e60537`).

## Removed

- DXT support and its frontend components and services (`849a8117`).

## Fixed

- Live threads are merged into the thread list, with error handling on load (`d47fe37b`), and the list refreshes when the provider filter changes (`0b9b4be6`).
- Transient connection errors now show a retry notice instead of failing silently (`714664f6`).
- Terminal buffer is no longer lost when the container reports invalid dimensions (`b2fe901f`).
- Clickable elements have proper button semantics and stable keys (`356cffb2`).
- The pre-commit hook no longer silently drops staged work (`989985cb`).
- The remote recommendation URL points at `master` instead of `main` (`5e963715`).

## Internal

Version bumping moved from a Python script to a Node-based `bump-version` script, lint-staged was dropped, event rendering was refactored into an `EventItem` component, effect dependencies were corrected, the README was trimmed, auto-generated Info.plist bundle metadata keys were removed, and the Plux promo UI was updated to use the external URL hook.
