# 0.43.0 - 2026-08-09

[Compare with 0.42.2](https://github.com/milisp/codexia/compare/v0.42.2...v0.43.0)

## Added

- **Agent Client Protocol (ACP)** — connect external agents over ACP. Sessions persist across restarts, and tool call updates render live in the thread (`fe03ce0f`, `5e217772`).
- **iOS remote control** — drive Codexia from an iOS app over an authenticated web server (`82fa7971`).
- **Grok approval toggle** in agent settings (`12783a4c`).

## Changed

- Model and reasoning effort settings consolidated into a single settings surface (`12783a4c`).
- Git diff panel state moved into a dedicated `useGitDiffStore` (`8e5317dc`).
- `AgentView` shows a Plux promo for cross-app text capture (`74132361`).

## Fixed

- Remote clients now share the desktop's ACP state instead of starting their own (`5768a357`).
- Keyboard focus styles restored on `Select` (`2b3e0896`).
- React types pinned to a single copy, fixing duplicate-type errors in editors and `tsc` (`eb99eb41`).

## Internal

Husky pre-commit hook with lint-staged, biome formatting pass, tailwindcss moved to devDependencies, Plux added to the README ecosystem list.
