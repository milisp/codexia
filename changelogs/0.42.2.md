## [0.42.2]

### 🚀 Features
* **UI / Workspace**: Introduce a dynamic multi-tabbed interface for the right panel with support for opening, closing, and selecting tabs (`04f15ced`)
* **Git & Diffs**: 
  * Add Git revert functionality to `ThreadFileChangesSummary` supporting per-file and bulk undo (`39da0aad`)
  * Add hover preview for file changes using `DiffViewer` in `ThreadFileChangesSummary` (`3474c364`)
* **Protocol**: Bump `codex-app-server-protocol` to `0.146.0` with experimental bindings (`bd15f726`)

### 🛠 Refactoring & Improvements
* **State Management**: 
  * Split `useWorkspaceStore` into dedicated `workspace`, `editor`, and `agent-settings` stores (`4c4817bf`)
  * Remove `StoreErrorBoundary` component from the main App layout (`7c904de3`)
* **Diff Viewer**: 
  * Replace inline diffs with a compact `ThreadFileChangesSummary` (`100517d1`)
  * Add bulk expand/collapse controls to full `DiffViewer` components (`100517d1`)
  * Consolidate line number display and reduce column width in `DiffViewer` (`04657850`)
