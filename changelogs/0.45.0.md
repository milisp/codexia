# 0.45.0 - 2026-08-16

[Compare with 0.44.0](https://github.com/milisp/codexia/compare/v0.44.0...v0.45.0)

## Added

- **iOS app rebuilt on Tauri** — the hand-written SwiftUI client is gone, replaced by a Tauri iOS target that reuses the React frontend, with mobile runtime detection and a new pairing view (`f8324882`, `e509dedb`).
- **Mobile shell** — a dedicated mobile home with project browsing, the pairing flow, keyboard inset handling and remote access settings (`a49fa3ac`).
- **Multiple paired desktops** — pair several machines, switch between them from a drawer, or unpair one; switching or unpairing the active desktop reloads the view so the previous machine's threads never leak into the new one's lists (`2c8c34b1`).
- **Multiple sessions per ACP agent connection** — one agent process can now host several sessions, and resuming a session from another project reuses the running process (`11c627c1`).

## Fixed

- The first file opened after showing the right panel stayed blank until you switched files (`0b1f0589`).
- Toggling focus mode unmounted the right panel and reset long-lived children such as the terminal; the panel now stays mounted (`db9748a5`).

## Removed

- The Codex account/auth panel and its account state in the codex thread view (`0e1ec221`).

## Internal

Thread list refreshing now uses a seen-id tracker instead of an explicit trigger state, and the README gained ACP details, project badges, maintainer links and a separate Plux section.
